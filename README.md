# University JPA API — Pruebas unitarias

Proyecto derivado de [university-jpa-api](https://github.com/khalif555/university-jpa-api).

## Descripción

API REST para la gestión de departamentos, profesores, cursos y estudiantes, desarrollada con Spring Boot y JPA.

## Trabajo realizado

* Se agregaron pruebas unitarias con JUnit 5.
* Se utilizó Mockito para simular dependencias.
* Se agregaron pruebas para servicios, controladores, excepciones y configuración CORS.
* Se configuró JaCoCo para medir la cobertura del código.
* Se alcanzó una cobertura aproximada del **92%**.
* Se agregó configuración para excluir archivos generados por Maven mediante `.gitignore`.

## Tecnologías

* Java 17
* Spring Boot
* Spring Data JPA
* JUnit 5
* Mockito
* JaCoCo
* Maven
* H2 Database

## Referencia

El proyecto original fue desarrollado por **khalif555**. Este repositorio es un fork en el que se agregaron pruebas unitarias y configuración de cobertura.
